# Веб-интерфейс системы заявок на ремонт лифтов

## Общее описание

Веб-интерфейс предназначен для операторов диспетчерской службы. Позволяет создавать заявки, назначать механиков, отслеживать статус выполнения и управлять справочниками.

**URL:** http://tickets.lift-system.crazedns.ru

---

## Главная страница (Дашборд)

**Маршрут:** `/` или `/tickets`

### Статистические карточки

| Карточка | Описание | Клик |
|----------|----------|------|
| Всего заявок | Общее количество заявок в системе | Фильтр "Все" |
| Поступило (с 08:00) | Заявки, поступившие в текущую смену (08:00-08:00) | Фильтр "Новые" |
| В работе (всего) | Заявки со статусом "в работе" | Фильтр "В работе" |
| Выполнено (с 08:00) | Заявки выполненные в текущую смену | Фильтр "Выполнено" |

### Карточки заявок

Каждая карточка заявки содержит:
- **ID заявки** - номер (формат: ГГММДД-NNNN)
- **Адрес** - улица, дом, подъезд
- **Описание** - краткое описание проблемы
- **Время** - время поступления
- **Бейджи**:
  - 🔴 Срочный / 🟠 Высокий / 🔵 Обычный / 🟢 Низкий - приоритет
  - 🆕 Новая / 🔧 В работе / ✅ Выполнена - статус
- **Фото** - превью (если есть)
- **Механик** - кто выполняет (если назначен)

### Фильтры

- **Поступило** - новые заявки
- **В работе** - заявки в процессе выполнения
- **Выполнено** - завершённые заявки
- Поиск по адресу или ID

### Меню (右上角)

```
├─ Настройки уведомлений
├─ Справочник лифтов
├─ Механики
├─ Аварийные дежурства
├─ База знаний (внешняя ссылка)
├─ Сделать бэкап
├─ Восстановить из бэкапа
├─ Справка
└─ О программе
```

## Новая заявка

**Маршрут:** `/new-ticket`

### Поля формы

| Поле | Обязательно | Описание |
|------|-------------|----------|
| Адрес | ✅ | Адрес дома с лифтом |
| № лифта | ✅ | Идентификатор лифта (выбор из справочника) |
| Подъезд | - | Номер подъезда |
| Описание проблемы | ✅ | Текстовое описание неисправности |
| Приоритет | ✅ | Срочный / Высокий / Обычный / Низкий |
| Имя клиента | - | Имя позвонившего |
| Телефон клиента | - | Контактный телефон |
| Фото подъезда | - | Загрузка фото |

### Логика отправки

После создания заявки:
1. Проверяются настройки уведомлений
2. **Линейный механик** (закреплён за лифтом) получает заявку:
   - Только в рабочее время (08:00-17:00, пн-пт)
   - Если включено в настройках
3. **Аварийный механик** (дежурный) получает заявку:
   - Всегда (кроме низкого приоритета)
   - Если включено в настройках

## Детали заявки

**Маршрут:** `/ticket/<id>`

### Секции

1. **Информация о заявке**
   - Номер, адрес, статус, приоритет
   - Дата создания, время в статусе

2. **История статусов**
   - Хронология изменений: Новая → В работе → Выполнена
   - Кто изменил и когда

3. **Комментарии**
   - Сообщения от операторов
   - Отчёты от механиков (с фото)
   - Системные события

4. **Действия** (для оператора)
   - Назначить механика
   - Изменить статус
   - Добавить комментарий
   - Отменить заявку

## Справочник лифтов

**Маршрут:** `/elevators`

### Возможности

- Просмотр всех лифтов
- Поиск по адресу или ID
- Добавление нового лифта
- Редактирование данных
- Закрепление механиков за лифтом
- Загрузка фото лифта

### Карточка лифта

- ID лифта
- Адрес
- Тип (пассажирский/грузовой)
- Закреплённые механики
- Количество заявок

## Механики

**Маршрут:** `/mechanics`

### Карточка механика

- ФИО
- Телефон
- Max ID (для уведомлений)
- Статус (active/inactive)
- Закреплённые лифты

### Действия

- Добавить механика
- Редактировать
- Удалить (только неактивных)

## Аварийные дежурства

**Маршрут:** `/oncall`

### Функционал

- Просмотр дежурного на сегодня/завтра
- Назначение дежурного
- История дежурств (последние 10)

### Логика

- Аварийный получает заявки круглосуточно
- Дежурство: с 08:00 до 08:00 следующего дня
- Автоматическая ротация при отсутствии назначения

## Настройки уведомлений

**Маршрут:** `/settings`

### Параметры

| Настройка | Описание | По умолчанию |
|-----------|----------|--------------|
| Линейный механик | Отправлять заявки закреплённому механику | Включено |
| Аварийный механик | Отправлять заявки дежурному | Включено |

### Условия отправки

**Линейный:**
- Рабочее время (08:00-17:00)
- Будние дни (пн-пт)
- Если не выходной

**Аварийный:**
- Всегда (кроме низкого приоритета)
- Если не отключено в настройках

## Бэкап и восстановление

### Создание бэкапа

Меню → Сделать бэкап
- Скачивается ZIP-архив
- Содержит: база данных + фото

### Восстановление

Меню → Восстановить из бэкапа
- Загрузить ZIP или DB файл
- Текущие данные заменяются

## Max бот для механиков

**URL бота:** https://max.ru/id732606860856_bot

### Функционал для механика

1. **Регистрация**
   - Отправить номер телефона (формат: +79991234567)
   - Привязка к профилю в системе

2. **Меню бота**
   - 🛗 Мои лифты - список закреплённых лифтов
   - 📋 Мои заявки - активные заявки
   - ❓ Помощь - справка
   - ✅ Завершить заявку - выполнить работу

3. **Получение заявки**
   - Уведомление с адресом и описанием
   - Кнопка "Принять в работу"
   - Кнопка "Завершить"

### Регистрация механика

1. Механик запускает бота
2. Отправляет номер телефона
3. Система ищет по базе
4. Привязывает Max ID к профилю
