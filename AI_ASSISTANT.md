# AI-ассистент для Max бота механиков

## Концепция

AI-ассистент помогает механику быстро получать информацию о заявках, диагностировать неисправности, искать в базе знаний и составлять отчёты.

---

## Функции AI

### 1. 📋 Информация о заявке

```
Пользователь: "Что за заявка #20260409-0001?"
AI: Анализирует заявку и выводит краткую сводку:
    📍 Адрес: ул. Ленина 10, подъезд 1
    ⚡ Приоритет: Обычный
    📝 Проблема: Не работает кнопка вызова лифта
    👤 Клиент: Иванова Мария, +79991234567
    📊 Статус: Новая (2 часа назад)
```

### 2. 🔧 Диагностика неисправностей

```
Пользователь: "Лифт не открывает двери, что проверить?"
AI: Предлагает алгоритм диагностики:
    1. Проверить питание кабины (есть/нет индикация)
    2. Проверить концевики дверей (контакты, механизм)
    3. Проверить привод дверей (двигатель, редуктор)
    4. Проверить датчики безопасности
    5. Проверить панель управления
```

### 3. 📖 Поиск в базе знаний

```
Пользователь: "Как заменить трос?"
AI: Ищет в repair_reports и выводит похожие ремонты:
    Найдено 3 похожих ремонта:
    1. Замена тяговых тросов - Л1-05 - 2024-03-15
       Работа: Замена 4 тросов, работа 4 часа
    2. Обрыв троса - Л2-12 - 2024-02-10
       Работа: Замена комплекта тросов, 6 часов
    3. Профилактика тросовой группы - Л1-08 - 2024-01-20
       Работа: Смазка, проверка натяжения
```

### 4. 📝 Помощь с отчётом

```
Пользователь: "Помоги написать отчёт"
AI: Запрашивает данные и генерирует шаблон:
    Для заявки #20260409-0001:
    Шаблон отчёта:
    ---
    Выполненные работы:
    1. [опишите работу]
    2. [опишите работу]
    
    Использованные запчасти:
    - [наименование, кол-во]
    
    Время работы: [часы]
    
    Примечание: [доп. информация]
    ---
```

### 5. ❓ Общие вопросы

```
Пользователь: "Как отключить лифт для обслуживания?"
AI: Даёт инструкцию с учётом правил безопасности:
    Порядок отключения лифта:
    
    1. Поставить предупреждающий знак
    2. Перевести в режим "Техническое обслуживание"
    3. Отключить главный автомат
    4. Перевести кабину на нижний этаж
    5. Заблокировать двери шахты
    6. Проверить отсутствие напряжения
    
    ⚠️ Все работы выполнять вдвоём!
```

```python
SYSTEM_PROMPT = """

Правила:
1. Отвечай кратко и по существу

3. Если нужна доп. информация - спрашивай
4. Не давай опасные советы
5. Используй данные из базы если доступны

```

## Конфигурация

### Подключение к LM Studio

```python
import requests

LM_STUDIO_URL = "http://192.168.0.38:1234/v1/chat/completions"
LM_API_TOKEN = "sk-lm-M6IENXKx:sL6tLQPn6pF792Bv2jQ2"
LLM_MODEL = "qwen2.5-3b-instruct"

def ask_ai(prompt, context=None):
    headers = {
        "Authorization": f"Bearer {LM_API_TOKEN}",
        "Content-Type": "application/json"
    }
    
    messages = [{"role": "system", "content": SYSTEM_PROMPT}]
    
    if context:
        messages.append({"role": "system", "content": f"Контекст: {context}"})
    
    messages.append({"role": "user", "content": prompt})
    
    data = {
        "model": LLM_MODEL,
        "messages": messages,
        "max_tokens": 500,
        "temperature": 0.7
    }
    
    response = requests.post(LM_STUDIO_URL, headers=headers, json=data, timeout=60)
    return response.json()["choices"][0]["message"]["content"]
```

### Обработка ошибок

```python
def safe_ask_ai(prompt, context=None):
    try:
        return ask_ai(prompt, context)
    except requests.exceptions.Timeout:
        return "⏳ AI занят, попробуйте позже"
    except ConnectionError:
        return "🔌 Нет связи с AI-сервером"
    except Exception as e:
        return f"❌ Ошибка: {str(e)}"
```
